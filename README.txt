مكتب الجمعية الشرعية - مشروع Front-End
========================================

المشروع يعمل بالكامل من الواجهة الأمامية فقط، ولا يحتاج Backend أو قاعدة بيانات.

طريقة التشغيل:
1) افتح index.html في المتصفح أو باستخدام Live Server.
2) اضغط "تسجيل الدخول".
3) الحسابات التجريبية:
   - طالب: student / 1234
   - معلم: teacher / 1234
   - إدارة: admin / 1234

الربط بين اللوحات:
- البيانات المشتركة محفوظة في localStorage.
- الطالب رقم 1 مرتبط بحلقة الحفظ والمراجعة مع الشيخ محمد سعدالله.
- لوحة المعلم تعرض الطلاب التابعين للمعلم الحالي فقط.
- لوحة الإدارة تعرض جميع الطلاب والحلقات والتسميع.
- التسميع والحضور وتعديلات الطلاب تنتقل بين اللوحات عبر localStorage.
- إشعارات الإدارة تظهر في لوحة الطالب.

مهم:
- المشروع لا يستخدم أي API خارجي.
- لا يوجد Backend.
- لو كنت قد جربت نسخة قديمة على نفس المتصفح، استخدم حسابات التجربة الجديدة بعد فتح النسخة الجديدة. البيانات القديمة في localStorage قد تستمر لأنها مرتبطة بالمتصفح.


اختبار تسجيل الدخول:
1) افتح index.html.
2) اضغط تسجيل الدخول.
3) اختر نوع الحساب.
4) استخدم اسم المستخدم student أو teacher أو admin وكلمة المرور 1234.
5) سيتم فتح لوحة الحساب مباشرة.
المشروع Front-End فقط ويستخدم localStorage.


إضافة طالب جديد بنفسك:
1) افتحي لوحة الإدارة بالحساب admin / 1234.
2) من قسم الطلاب اضغطي إضافة طالب جديد.
3) اكتبي اسم الطالب، اسم المستخدم، كلمة المرور، السن، الحلقة والمستوى.
4) احفظي الطالب.
5) الطالب يستخدم اسم المستخدم وكلمة المرور اللذين أدخلتهما الإدارة للدخول.
6) الحلقة والمعلم يتحددان تلقائيًا حسب الحلقة المختارة.
البيانات تحفظ في Local Storage لأنها نسخة Front-End فقط.


إضافات النسخة الأخيرة:
- حماية لوحات الطالب والمعلم والإدارة بصلاحيات Front-End عبر localStorage.
- بحث وتصفية الطلاب في لوحة الإدارة بالاسم والحلقة والمعلم.
- رسائل نجاح مرئية عند تنفيذ العمليات.
- صفحة 404 بسيطة للمسارات غير الموجودة.
- المشروع Front-End فقط ولا يحتاج Backend.
